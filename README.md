# مكتبة إسلام | Islam Library POS & ERP 📚

نظام إدارة مبيعات ومخازن احترافي متكامل مصمم للعمل كـ Desktop Application (تطبيق سطح مكتب) بنظام Offline-first.

---

## 🚀 كيفية التشغيل (للمطورين) - How to Run (Development)

للتمكن من تشغيل النظام على جهازك، يجب أن يكون لديك **Node.js** مثبتاً.

1. **تحميل المشروع:**
   قم بتحميل الملفات إلى جهازك.

2. **تثبيت المكتبات البرمجية:**
   افتح واجهة الأوامر (Terminal/CMD) في مجلد المشروع وقم بتشغيل:
   ```bash
   npm install
   ```

3. **تشغيل البرنامج في وضع التطوير:**
   ```bash
   npm start
   ```

---

## 📦 كيفية بناء ملف التشغيل (EXE) - Build for Windows

لتحويل النظام إلى برنامج قابل للتثبيت على ويندوز:

1. قم بتشغيل أمر البناء:
   ```bash
   npm run build
   ```
2. ستجد ملف الـ `Installer` الناتج في مجلد باسم `dist`.

---

## 🛡️ نظام الترخيص (License System)

عند تشغيل البرنامج لأول مرة، سيطلب كود تفعيل.
- يتم ربط النسخة بـ **Machine ID** الخاص بجهازك.
- يمكنك استخدام كود التفعيل الافتراضي للاختبار: `MY-SECURE-ACTIVATION-KEY-123` (في النسخة التجريبية).

---

## 🛠️ الميزات الأساسية:
- **شاشة بيع سريعة:** تدعم الباركود والخصومات.
- **إدارة كاملة للموردين:** شراء بضاعة وتتبع الديون.
- **نظام الموظفين:** سلف، رواتب، وكشف حساب.
- **الخزينة والدرج:** تتبع كافة الحركات المالية.
- **تقارير BI:** تحليل الأرباح وساعات الذروة والنواقص.

---

**ملاحظة:** البرنامج يعمل بالكامل بدون إنترنت (Offline) ويحفظ البيانات في قاعدة بيانات SQLite مشفرة محلياً.
